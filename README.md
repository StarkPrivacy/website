# Stark Privacy — Sitio web personal

Primera versión del sitio web personal.

- **Estado**: privado / en desarrollo
- **Enfoque**: página profesional con toques cypherpunk sutiles, integración de todos los enlaces de starkprivacy.com, espacio destacado para la Academia Boring Privacy y privacidad.me.
- Estilos inspirados en la claridad de estructura, limpieza moderna y base oscura + acentos azules.

## Cómo previsualizar

Puedes abrir el archivo `index.html` directamente en el navegador o clonar el repositorio y servirlos localmente.

Para activar **GitHub Pages** cuando lo desees:
1. Settings → Pages
2. Source: Deploy from a branch → `main` / root (o `/docs`)
